║  TerraCore — как добавить свой перевод                            ║
╚══════════════════════════════════════════════════════════════════╝

1. Имя файла → Язык
   ────────────────────────────────────────────────────────────────
   ru_ru.yml   → русский (Россия)
   de_de.yml   → немецкий (Германия)
   fr_fr.yml   → французский (Франция)
   pt_br.yml   → португальский (Бразилия)
   es_es.yml   → испанский (Испания)
   pl_pl.yml   → польский (Польша)
   tr_tr.yml   → турецкий (Турция)
   en_gb.yml   → английский (Великобритания)
   en.yml      → английский (без страны)

   Формат: <lang>_<COUNTRY>.yml  или  <lang>.yml
   Lang  — ISO 639-1 (2 буквы, lower-case)
   COUNTRY — ISO 3166-1 alpha-2 (2 буквы, UPPER-CASE)

2. Формат файла
   ────────────────────────────────────────────────────────────────
   # Комментарии начинаются с #
   "ключ": "MiniMessage value"

   ⚠ Ключи с точками ОБЯЗАТЕЛЬНО в кавычках!
   ⚠ Значение — MiniMessage (теги <red>, <gradient:...>, <sprite:...>)
   ⚠ Запятые в конце строки НЕ ставятся (это не полноценный YAML)

3. Откуда брать список ключей
   ────────────────────────────────────────────────────────────────
   Скопируйте en_us.yml и переведите значения.
   Или возьмите за основу ru_ru.yml.

   Все ключи обязательны, но если каких-то нет — будет fallback:
   - для CIS-стран (RU, BY, KZ, UA, ...) — fallback на ru_ru
   - для остальных — fallback на en_us

4. Проверка перевода
   ────────────────────────────────────────────────────────────────
   /tc lang — покажет список локалей, % заполнения, missing-ключи.

   Пример вывода:
     ✔ ru_RU · built-in · 100% (345/345)
     ⚠ de_DE · custom · 87% (300/345)
          god.enabled.self, god.disabled.self, fly.enabled.self, ...

5. Перезагрузка без рестарта
   ────────────────────────────────────────────────────────────────
   /tc reload — перечитает lang/ и config.yml.

   ⚠ Важно: LangManager НЕ перезаписывает существующие файлы,
   только дополняет недостающими ключами из JAR.

6. Как игрок выбирает язык
   ────────────────────────────────────────────────────────────────
   Автоматически — по локали клиента (player.locale()).

   Пример: игрок с клиентом на немецком (de_DE) увидит de_DE.yml,
   если файл существует. Иначе — en_us.

7. Палитра (рекомендуемая)
   ────────────────────────────────────────────────────────────────
   <aqua>       — акцент (игроки, мир, координаты)
   <green>      — успех
   <yellow>     — предупреждение
   <red>        — ошибка
   <gold>       — значения (числа, тики)
   <gray>       — вторичный текст
   <dark_gray>  — разделители, UUID, IP
